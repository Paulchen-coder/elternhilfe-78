Potenzgesetze

Potenzen begegnen Kindern in vielen Bereichen der Mathematik. Die Potenzgesetze helfen dabei, Ausdrücke zu vereinfachen und Zusammenhänge besser zu verstehen. Diese Seite erklärt die Regeln so, dass Eltern sie sicher weitergeben können.

Was ist eine Potenz?

Eine Potenz besteht aus zwei Teilen:

  • Basis (z. B. 3)
  • Exponent (z. B. 4)

3⁴ bedeutet: 3 · 3 · 3 · 3 = 81

Die wichtigsten Potenzgesetze

1. Gleichnamige Basen multiplizieren

Wenn die Basis gleich ist, werden die Exponenten addiert.

aᵐ · aⁿ = aᵐ⁺ⁿ

Beispiel: 2³ · 2⁴ = 2⁷

2. Gleichnamige Basen dividieren

Wenn die Basis gleich ist, werden die Exponenten subtrahiert.

aᵐ / aⁿ = aᵐ⁻ⁿ

Beispiel: 5⁶ / 5² = 5⁴

3. Potenz einer Potenz

Hier werden die Exponenten multipliziert.

(aᵐ)ⁿ = aᵐ·ⁿ

Beispiel: (3²)³ = 3⁶

4. Produkt potenzieren

Jeder Faktor bekommt den Exponenten.

(ab)ⁿ = aⁿ · bⁿ

Beispiel: (2 · 5)³ = 2³ · 5³

5. Quotient potenzieren

Auch hier bekommt jeder Teil den Exponenten.

(a/b)ⁿ = aⁿ / bⁿ

Beispiel: (4/2)² = 4² / 2²

6. Exponent 0

Jede Zahl hoch 0 ist 1.

a⁰ = 1

Beispiel: 7⁰ = 1

7. Exponent 1

Eine Zahl hoch 1 bleibt die Zahl selbst.

a¹ = a

Beispiel: 9¹ = 9

Typische Fehler von Kindern

  • Basis und Exponent verwechseln
  • Exponenten falsch addieren oder subtrahieren
  • Beim Potenzieren von Produkten nur einen Faktor potenzieren
  • „a⁰ = 0“ statt „a⁰ = 1“
  • Negativen Exponenten falsch interpretieren

So erklären Sie es Ihrem Kind

1. Nutzen Sie kleine Beispiele.
Kinder verstehen Regeln besser, wenn sie konkrete Zahlen sehen.

2. Zeigen Sie die Muster.
„Beim Multiplizieren addieren wir die Exponenten.“

3. Lassen Sie Ihr Kind eigene Beispiele bilden.

4. Wiederholen Sie die Grundregeln regelmäßig.

Kleine Übung

  • Vereinfachen Sie: 3² · 3³
  • Vereinfachen Sie: 5⁷ / 5³
  • Berechnen Sie: (2³)²
  • Berechnen Sie: (4 · 3)²
  • Berechnen Sie: 9⁰
Lösungen anzeigen
  • 3² · 3³ = 3⁵
  • 5⁷ / 5³ = 5⁴
  • (2³)² = 2⁶
  • (4 · 3)² = 4² · 3² = 16 · 9 = 144
  • 9⁰ = 1
