Datenschutz

Der Schutz Ihrer persönlichen Daten ist uns wichtig. Diese Website ist ein schulisches Informations- und Hilfsangebot. Wir versuchen, den Umfang der auf dieser Website anfallenden Daten so gering wie möglich zu halten.

1. Verantwortlicher

Verantwortlich für den Inhalt dieser Website ist die im Impressum genannte Stelle.

2. Welche Daten werden auf dieser Website erhoben?

Auf der Website selbst werden keine Benutzerkonten angelegt und keine personenbezogenen Daten über ein Registrierungsformular erhoben. Die Suchfunktion arbeitet mit einem lokalen Suchindex der Website. Die von Ihnen eingegebenen Suchbegriffe werden nicht von uns in einem Benutzerkonto gespeichert.

3. Hosting durch GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf einer GitHub-Pages-Website wird die IP-Adresse des Besuchers laut GitHub aus Sicherheitsgründen protokolliert und gespeichert. Diese Verarbeitung erfolgt durch GitHub als Anbieter des Hosting-Dienstes und liegt nicht in unserem eigenen Zugriff. Weitere Informationen finden Sie in der Dokumentation zu GitHub Pages und in der Datenschutzerklärung von GitHub.

4. Cloudflare Web Analytics

Wir verwenden Cloudflare Web Analytics, um die Nutzung und die technische Leistung der Website besser einschätzen zu können. Cloudflare beschreibt Web Analytics als datenschutzorientierte, cookie-freie Analyse. Nach Angaben von Cloudflare werden dabei keine personenbezogenen Daten der Besucher für Web Analytics gesammelt und Besucher nicht über verschiedene Websites hinweg verfolgt.

Der dafür verwendete Dienst lädt ein kleines JavaScript von static.cloudflareinsights.com. Cloudflare Web Analytics verwendet Leistungsdaten des Browsers, insbesondere Messwerte zur Lade- und Darstellungsleistung der aufgerufenen Seite. Nach Angaben von Cloudflare werden hierfür weder Cookies noch Local Storage eingesetzt und es findet kein individuelles Fingerprinting anhand der IP-Adresse oder des User-Agent statt.

Weitere Informationen finden Sie in der Dokumentation zu Cloudflare Web Analytics und zur Datenerhebung von Web Analytics.

5. Keine Werbe- oder Trackingdienste

Auf dieser Website werden keine personalisierten Werbeanzeigen geschaltet. Es werden keine Social-Media-Tracker und keine Analysewerkzeuge wie Google Analytics eingesetzt.

6. Externe Inhalte

Die Website ist grundsätzlich so aufgebaut, dass Inhalte und Suchdaten lokal von dieser Website bereitgestellt werden. Für externe Dienste gilt jeweils die Datenschutzerklärung des betreffenden Anbieters.

7. Aktualität dieser Datenschutzerklärung

Diese Datenschutzerklärung wird angepasst, wenn sich die technische Umsetzung der Website oder die eingesetzten Dienste ändern.
