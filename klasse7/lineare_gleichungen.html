Lineare Gleichungen

Lineare Gleichungen gehören zu den wichtigsten Grundlagen der Algebra. Kinder lernen hier, wie man eine Gleichung Schritt für Schritt löst und die gesuchte Zahl findet. Diese Seite erklärt das Thema so, dass Eltern es sicher weitergeben können.

Was ist eine Gleichung?

Eine Gleichung ist eine Aussage, dass zwei Terme gleich sind.

3x + 5 = 17

Die linke Seite (3x + 5) soll genauso groß sein wie die rechte Seite (17).

Ziel beim Lösen einer Gleichung

Das Ziel ist immer:

x alleine auf eine Seite bringen

Dafür „arbeitet“ man sich Schritt für Schritt vor.

Grundregeln

  • Was man links macht, muss man auch rechts machen.
  • Man löst die Gleichung in kleinen Schritten.
  • Man arbeitet sich von außen nach innen vor.

Beispiel: 3x + 5 = 17

1. Schritt: –5 auf beiden Seiten

→ 3x = 12

2. Schritt: ÷3 auf beiden Seiten

→ x = 4

Beispiel aus dem Alltag

Ihr Kind spart Geld. Jede Woche kommen 3 € dazu. Nach einiger Zeit hat es 17 €.

3x + 5 = 17

5 € waren schon vorher da.

x = Anzahl der Wochen → x = 4

Gleichungen mit Klammern

Klammern müssen zuerst aufgelöst werden.

2(x – 3) = 10

→ 2x – 6 = 10

→ 2x = 16

→ x = 8

Gleichungen mit beiden Seiten x

Hier bringt man zuerst alle x‑Terme auf eine Seite.

5x – 3 = 2x + 9

→ 5x – 2x = 9 + 3

→ 3x = 12

→ x = 4

Typische Fehler von Kindern

  • Nur auf einer Seite etwas verändern
  • Klammern falsch auflösen
  • Vorzeichenfehler
  • Ungleichartige Terme zusammenfassen
  • Zu große Schritte auf einmal

So erklären Sie es Ihrem Kind

1. Gleichungen sind wie eine Waage.
Beide Seiten müssen gleich bleiben.

2. Kleine Schritte.
„Was stört x? Das räumen wir zuerst weg.“

3. Immer auf beiden Seiten arbeiten.

4. Zwischenergebnisse aufschreiben.

Kleine Übung

  • Lösen Sie: 4x – 7 = 21
  • Lösen Sie: 2(x + 3) = 18
  • Lösen Sie: 6x + 5 = 3x + 20
Lösungen anzeigen
  • 4x – 7 = 21 → 4x = 28 → x = 7
  • 2(x + 3) = 18 → 2x + 6 = 18 → 2x = 12 → x = 6
  • 6x + 5 = 3x + 20 → 3x = 15 → x = 5
